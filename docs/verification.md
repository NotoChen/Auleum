# 验证记录

Auleum 的采集透明性和失败保护来自实测，不是推断。旧版本的结果不代表当前版本；下表注明日期和版本。

测试机：Apple M1、双屏（内置 Retina + DELL 1920×1080）、macOS 27.2。目标系统是 macOS 14+，但 macOS 14/15 的 gamma 行为、权限面板名称和 ScreenCaptureKit 兼容性仍需单独实测。

2026-11-25 起公开版本号重置为 **0.0.1**；更早记录里的内部预发布编号也统一按 0.0.1 记录。

## 当前源码

2026-11-25（0.0.1 发布）：新增 GitHub Releases 更新检查与自动升级。启动后 8 秒检查一次、之后每 6 小时检查；下载 zip 后校验 SHA-256、Bundle ID、版本和代码签名，幕帘关闭且未录制时由安装脚本替换 app 并在新进程未启动时回滚。设置窗口新增「更新」页，状态面板新增更新卡片和手动检查按钮，`status` / `doctor` 暴露更新阶段。仓库名统一为 `NotoChen/Auleum`，版本重置为 0.0.1（build 1），移除 GitHub Actions CI；所有历史提交压缩为一次 commit，并发布 zip、DMG 和 SHA-256 产物。`./Scripts/test.sh` 为 **89 tests / 16 suites** 全通过。更新检查/下载/安装脚本的端到端替换和界面截图仍待本次发布流程完成后确认。

2026-11-24：展示模式四种版式、默认渐变背景、组件开关、自由拖拽排版、组件底板和幕布颜色自适应完成；撤幕路径新增请求来源审计，Touch ID 不可用时不再直接撤幕；tap、权限、覆盖、睡眠和锁屏失败均严格保持幕帘。`./Scripts/test.sh` 为 **70 tests / 13 suites** 全通过；已生成四种版式、自定义位置、稀疏组件、明暗设置页和三种幕布配色/底板组合的预览，**已替换 `/Applications/Auleum.app`，TCC 重新授权和真机验收待人工完成**。自由排版目前验证的是共享画布的渲染与配置归一化，拖拽手势和真实全屏幕帘仍需在安装版上人工确认。

2026-11-25：修复认证期间露出 Dock/菜单栏的问题。用 `CGWindowListCopyWindowInfo` 实测系统 Touch ID 面板（`coreautha`）层级为 **1000**，Dock 为 **20**，菜单栏为 **24**；原实现把认证覆盖层降到 **0**，因此验证前会露出 Dock。现在认证覆盖层使用 **101**（`.popUpMenu`），仍在 Dock/菜单栏之上、系统面板之下；新增层级不变量测试。`./Scripts/test.sh` 为 **71 tests / 14 suites** 全通过，安装版待重新授权后人工复验。

2026-11-25（同日稍后）：撤幕认证改为幕帘内的自定义 Touch ID 卡片，使用 Apple `LAAuthenticationView`（`LocalAuthenticationEmbeddedUI`）。样机确认指纹图标在卡片内渲染，系统 `coreautha` 的 1000 层认证面板不再出现；卡片窗口在 **102** 层，覆盖层仍在 **101** 层。布局复测发现 `LAAuthenticationView` 会自己撑到 128×128，已按 128 重新排布并加容器裁剪，避免与文字重叠。同时起幕前增加 Touch ID 可用性检查：不可用时拒绝起幕，避免开启后无法退出。`./Scripts/test.sh` 为 **71 tests / 14 suites** 全通过，安装版待重新授权后人工复验。

2026-11-25（密码兜底）：新增 `allowPasswordFallback`，默认关闭。开启后 Touch ID 不可用（无硬件、被锁定或暂时不可用）或指纹验证失败时使用系统 `.deviceOwnerAuthentication` 密码面板，用户按 Esc 取消不回退；密码由 `coreautha` 处理，Auleum 不接触明文。面板期间输入策略改为放行物理键鼠、拦截合成键鼠和系统手势，物理 Esc 取消认证，鼠标指针临时显示；起幕守卫改为「Touch ID 可用，或密码兜底已开启且系统验证可用」。新增配置默认值/往返和输入策略测试。`./Scripts/test.sh` 为 **73 tests / 14 suites** 全通过；密码面板样式、合成输入拦截、Esc 取消和 `veil_off reason=password` 仍待在安装版上人工验证，尤其需要一台无 Touch ID 的 Mac 或暂时锁定 Touch ID 的样机。

2026-11-25（动态消息与审计尾部）：新增 `auleumctl message`，Agent 可在不撤幕的情况下更新展示模式上的单行进度消息；消息折叠空白和控制字符、最多 200 字，起幕/撤幕清空并回落到场景提示，审计只记录长度和是否可见。`auleumctl status` 新增当前认证方式、密码兜底和动态消息状态。`auleumctl audit` 的尾部读取改为最多 8 MB，避免长日志整份载入内存。`./Scripts/test.sh` 为 **77 tests / 15 suites** 全通过；动态消息在真实幕帘上的换行、截断和多屏显示仍待人工确认。

2026-11-25（降级可观测与配置保护）：`auleumctl status` 新增 `degraded` / `degraded_reason`，`doctor` 在降级时列出最近原因并把降级计入失败结论，菜单栏提示同步显示原因；恢复后清空。`doctor` 改为先在主线程快照配置、快捷键和电源状态，再在控制面队列执行审计校验和 SCK 探测，避免跨线程读 AppKit 状态。Touch ID 失败转入密码面板前先递增 generation，防止取消旧 context 触发的回调误判。配置文件无法解析时不再静默重置：原文件复制为 `config.corrupt-<时间戳>.json`（0600），默认配置继续运行，`status` / `doctor` 和审计 `config_load_failed` 都会报告。新增配置加载/损坏备份测试和单字段类型容错测试。另把认证中的菜单栏提示和状态面板改为按方式显示「等待 Touch ID」或「等待密码验证」，认证失败/取消后在展示模式给出短暂重试提示；状态面板新增「保护降级」卡片，设置页新增「开机自启」开关。已用共享画布生成降级状态、密码验证状态的状态面板预览和带开机自启行的设置页预览（含 820×620 最小窗口），确认卡片高度、警示色、滚动和文案布局。`./Scripts/test.sh` 为 **81 tests / 15 suites** 全通过；安装版待在重新授权后确认新增状态字段和开机自启开关。

## 仍需人工复验

- 物理键盘/鼠标拦截、三/四指系统手势、Mission Control、Dock、通知中心和全屏应用。
- 真实 Touch ID 成功解锁；自动测试覆盖的是状态机和失败路径。
- 自定义 Touch ID 卡片的成功、失败和 Esc 取消；样机验证了 UI 呈现，完整撤幕流程仍待授权后真机确认。
- 密码兜底路径：系统密码面板的层级和样式、物理键鼠输入、合成键鼠拦截、Esc 取消、失败后重新隐藏指针，以及 `veil_off reason=password` 审计。
- 真实合盖运行；目前只验证了电源断言和模拟显示器休眠。
- macOS 14/15 上的权限面板、gamma 和 ScreenCaptureKit 行为。
- HDMI、采集卡和私有采集 API；这些路径不受展示窗口排除保证。
- 真实物理 HID 触发的回座提示。
